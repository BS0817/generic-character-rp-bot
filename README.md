# Generic Character RP Bot

사용자가 직접 캐릭터, 장소, 세계관을 정의할 수 있는 **범용 멀티 캐릭터 Discord RP 봇 프레임워크**입니다.

여러 캐릭터 봇이 하나의 세계 안에서 각자의 생활 상태를 가지며 이동하고, 자율적으로 말하고, 서로 대화하고, 사용자와 관계와 기억을 쌓도록 구성되어 있습니다.

> 소스 버전: **v0.1.5** · Windows 정식 배포 여부는 Releases를 확인하세요


## v0.1.5 — 공통 프롬프트와 선택형 생활 확장

Setup의 **세계관 · 기능**에서 새 기능을 각각 켜고 끌 수 있습니다. 관리 화면의 검색·필터·기억 삭제·실행 기록은 항상 사용할 수 있습니다. 저장 후 봇을 재시작하면 적용됩니다.

- **공통 프롬프트:** 세계 규칙과 분리한 최우선 행동·대화 규칙, 편집과 기본 규칙 복원. Discord 인식 방식은 공통 규칙에 포함하지 않습니다.
- **대화 방식:** 월드, 개인·공동 RP, DM에 현장 RP / 메신저 RP / 직접 설정을 지정합니다. 개인 RP와 DM은 세계 기본값을 상속할 수도 있습니다.
- **프롬프트 작성 가이드:** 정체성·성격·말투·예시·외형·취향·관계·중요 설정·금지 묘사·추가 설명을 작성하고 미리보기에서 적용합니다. 예시 안내는 저장 내용에 섞이지 않으며 직접 편집도 유지합니다.
- **복장 취향:** 선호 스타일·색과 소재·비선호·싫어함·추가 설명. 전역 기능과 캐릭터별 사용 설정을 모두 켜야 반영됩니다. 취향은 소유나 현재 착용 사실로 취급하지 않습니다.
- **대화 검사:** 최근 발언 반복, 동의 연쇄, 상투적인 허락 질문과 일부 고정 관계 위반을 검사합니다. 초안은 최대 한 번 재생성하고 계속 위반하면 발언을 보류합니다. 사용자가 명시적으로 반복을 요청한 경우는 반복 검사에서 제외합니다. 검사는 규칙 기반이므로 의미상 모든 위반을 감지하지는 못합니다.
- **모니터링:** 이름·장소·활동 검색, 연결·수면·외출 필터, 허기·피로·장소 정렬, 허기·피로·기분·좌석·생활 단계·발언 대기·다음 월드 자율 판단·정지 상태·이동 보류 이유. 명령 실행/종료/오류와 생성·검사 결과도 표시합니다. 명령 처리 종료에는 권한 거부 안내로 끝난 경우도 포함됩니다.
- **기억 관리:** 선택 캐릭터의 최근 기억 100건과 대화 범위를 조회하고 확인 후 한 건씩 삭제합니다.
- **좌석:** 장소에 설정한 정원 안에서 자동 착석, 동석자와 빈자리 표시, 이동·취침·외출 시 해제합니다.
- **식사:** 장소별·시간대별 메뉴, 이전 메뉴와 다른 메뉴 우선, 준비→섭취→정리→완료. 섭취 단계에서만 허기가 감소하고 메뉴·식사 명칭은 유지됩니다. 이동 기능을 켠 경우 식사 완료 후 다른 활동/장소로 전환합니다.
- **낮잠:** 좌석 기능과 낮잠 허용 장소가 필요합니다. 낮 시간, 피로, 날씨·기온, 약속·대화·이벤트·진행 활동을 검사합니다. 짧은 낮잠 후 회복·스트레칭, 직접 호출 시 중단을 지원합니다. 정규 밤잠은 기존 개인실 규칙을 따릅니다.
- **수면 품질:** 정상·꿈·악몽·뒤척임과 방해 횟수에 따른 기상 피로. 악몽·뒤척임 이후에는 낮잠 기준을 낮춥니다.
- **물건 대여:** 실제 전달이 처리된 물건의 소유자·빌린 사람·반환 기록을 저장합니다. 명시적으로 빌려준 경우에만 대여로 기록하며, 일반 선물은 대여로 기록하지 않습니다.
- **단계별 활동:** 장소별로 등록한 훈련·조리·독서 등의 준비→진행→마무리, 진행 중 자동 이동 보류, 훈련·운동 피로 반영.
- **복장 상태:** 명시된 복장을 야외 비·눈 상황에서 젖음으로 표시하고 실내에서 건조 상태로 전환합니다. 새로운 의상이나 외투를 임의로 생성하지 않습니다.

공통 프롬프트·대화 검사·관계 검사·대화 방식은 기본 켜짐입니다. 복장 취향과 새 생활 확장은 기본 꺼짐으로, 장소와 캐릭터를 설정한 뒤 켜세요. 기존 설정 파일에 새 키가 없어도 같은 기본값을 사용합니다.

장소 관리의 좌석·메뉴 칸은 다음처럼 입력합니다.

```json
{"테이블 1": 4, "소파": 2}
```

```json
{"전체": ["차", "샌드위치"], "아침": ["토스트"], "저녁": ["수프", "파스타"]}
```

낮잠을 사용할 장소에는 좌석과 **낮잠 가능한 장소**를 설정하세요. 야외 장소는 **야외 장소**도 켜야 날씨 제한이 적용됩니다. 단계별 활동은 한 줄에 하나씩 입력합니다.

현재 PC 모니터는 최근 이벤트 200건을 보여줍니다. 이번 변경에는 DDL의 통계 그래프·다중 서버 독립 월드·Gateway/Worker 분리는 포함되지 않습니다. 기존 config·프롬프트·토큰·DB를 배포 예시로 덮어쓰지 마세요.

## 주요 기능

- 여러 Discord 캐릭터 봇을 하나의 프로그램에서 동시 실행
- 캐릭터별 프롬프트와 생활 습관 설정
- 장소별 Discord 채널 및 방문 가중치
- 수면 / 기상 / 외출 / 약속 / 자동 이동
- 캐릭터 자율발언 및 캐릭터끼리의 대화
- 사용자 및 캐릭터 관계 장기 기억
- 본서버 / 개인 RP 서버 / DM 상태 분리
- 종료 중 받은 사람의 멘션과 답글 복구
- 기능별 ON/OFF 설정
- RP 생활 시간대 설정
- `/서버초기화`를 통한 장소 채널 자동 생성
- Windows EXE 빌드 지원

## Windows 사용자

GitHub Releases에 Windows 배포 ZIP이 올라온 경우 Python 설치 없이 사용할 수 있습니다.

1. 배포 ZIP 압축을 풉니다.
2. `RPBot_Setup.exe`를 실행합니다.
3. 왼쪽 **API · Discord** 메뉴에서 API 키와 서버 ID를 입력하고 저장합니다.
4. **세계관 · 기능**, **장소**, **캐릭터**, **관계** 메뉴에서 설정합니다. 개인실을 사용하려면 장소 메뉴에도 개인실을 추가하세요.
5. 캐릭터 메뉴에서 봇 토큰과 프롬프트를 저장합니다. 프로필 이미지는 관리 화면에 표시되며 Discord 아바타를 바꾸지는 않습니다.
6. **시작하기 → 봇 실행** 또는 `RPBot.exe`로 봇을 실행합니다.
7. 필요하면 Discord에서 `/서버초기화`를 실행합니다.

### 설정 관리와 백업

새 `RPBot_Setup.exe`는 어두운 테마의 GUI입니다. 캐릭터·장소 추가/수정/삭제, 프롬프트, 초기 관계, 세계관, 16개 기능, 자율발언 간격과 대화 최대 턴을 관리할 수 있습니다. 기존 JSON의 추가 필드와 `.env`의 다른 값·주석은 유지합니다. 설정 저장 전에 `backup_setup/`에 설정·프롬프트·관리 화면 프로필·키를 백업합니다. **백업에 API 키와 토큰이 들어 있으므로 공유하지 마세요.**

설정 변경 후에는 봇 콘솔에서 Ctrl+C로 종료하고 다시 실행하세요. 삭제는 초기 관계·출입 제한·장소 참조를 정리하고, 학습된 기억·대화 기록·기존 프롬프트와 토큰은 남깁니다. 백업 복원은 해당 파일을 덮어쓰는 방식이며 이후에 추가된 파일이나 실제 대화 DB를 삭제하지 않습니다.

### 기존 사용자와 자동 업데이트

v0.1.2 이하에서 처음 변경할 때는 봇을 종료한 다음, 새 ZIP에서 `RPBot.exe`, `RPBot_Setup.exe`, `RPBot_Updater.exe` **세 실행 파일만** 기존 폴더로 복사하세요. 기존 `config/`, `prompts/`, `.env`, DB는 덮어쓰지 마세요.

이후에는 시작할 때 새 정식 버전을 확인하고, 설정 프로그램의 **업데이트** 메뉴에서 변경 사항을 읽은 뒤 설치할 수 있습니다. 자동 확인은 끌 수 있습니다. 업데이트 확인에 실패해도 봇 실행에는 영향을 주지 않습니다. 설치 전 봇을 종료해야 하며, SHA-256으로 다운로드를 검증하고 세 실행 파일만 교체합니다. 교체 실패 시 기존 실행 파일로 복구합니다. 완료 후 설정 프로그램이 다시 열리며, 봇은 사용자가 실행합니다.

이전 실행 파일은 설치 폴더의 `rpbot-update-*/previous/`에 보관됩니다. 업데이트가 정상 작동하는 것을 확인한 뒤 이 임시 폴더를 삭제할 수 있습니다. 업데이트는 GitHub 정식 릴리스의 Windows ZIP과 `.sha256`이 함께 있을 때 지원합니다. Python 소스 실행과 Railway에서는 GUI 자동 설치를 사용하지 않습니다.

## 소스에서 실행

Python 3.11 또는 3.12 권장.

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pip install -r requirements-gui.txt
python src/setup_gui.py

```

## 설정 파일

### `config/characters.json`
캐릭터 이름, Discord 토큰 환경변수, 프롬프트 파일, 개인실, 수면/기상 범위, 소지품, 습관, 목표, 장소 선호 등을 정의합니다.

### `config/places.json`
장소 이름, Discord 채널, 장소 설명, 주변 사물, 시간대별 방문 배율을 정의합니다.

### `config/relations.json`
캐릭터 사이에 시작 시점부터 이미 존재하는 관계만 정의합니다. 설정하지 않은 관계는 실제 상호작용을 통해 발전시킬 수 있습니다.

### `config/settings.json`
세계 이름과 설명, 공통 RP 규칙, 시간대, 기능별 ON/OFF를 관리합니다. 예시 파일의 `_설명` 항목은 엔진이 무시하므로 안내문으로 사용할 수 있습니다.

## 생활 시간

```json
"timezone": "Asia/Seoul"
```

`sleep_start_range`, `wake_range`, 약속, 시간대별 장소 이동은 이 시간대를 기준으로 계산합니다.

예:

```json
"sleep_start_range": [[1, 0], [3, 0]],
"wake_range": [[8, 0], [10, 0]]
```

위 설정은 생활 시간대 기준으로 01:00~03:00 사이에 취침하고 08:00~10:00 사이에 기상하는 스케줄을 매일 정합니다.

## 기능 ON/OFF

`config/settings.json`의 `features`에서 주요 기능을 켜거나 끌 수 있습니다.

```json
"features": {
  "world_simulation": true,
  "place_movement": true,
  "autonomous_messages": true,
  "bot_to_bot_chat": true,
  "long_term_memory": true,
  "relationships": true,
  "personal_rp": true,
  "dm": true
}
```

Discord에서 `/기능설정보기`로 현재 상태를 확인할 수 있습니다.

## Discord 서버 초기화

봇에 **채널 관리** 권한을 준 뒤 `/서버초기화`를 실행하면 `places.json`과 캐릭터 개인실 설정을 기준으로 없는 카테고리/채널을 생성합니다. 기존 채널은 삭제하거나 덮어쓰지 않습니다.

## EXE 직접 빌드

Windows에서 `build_exe.bat`을 실행합니다. 빌드 PC에는 Python이 필요하지만, 완성된 EXE를 사용하는 PC에는 Python이 필요하지 않습니다.

완료되면 `release/`에 다음 파일이 만들어집니다.

```text
release/
├─ RPBot.exe
├─ RPBot_Setup.exe
├─ README_KO.md
├─ config/
└─ prompts/
```

- **PC 모니터링:** `RPBot_Setup.exe → 모니터링`에서 봇 실행·정지, 캐릭터별 Discord 연결·응답 진행, 장소·활동·복장·마지막 응답, 채널별 최근 대화와 실행 기록을 확인합니다. `RPBot.exe`를 직접 실행해도 관리 창이 열립니다. 실행 중 창을 닫을 때 봇 종료 또는 트레이 최소화를 선택할 수 있습니다.
- **기억·설정 열람:** 선택한 캐릭터의 프로필·프롬프트와 최근 저장 기억을 읽을 수 있습니다. 모니터링에 표시하는 대화·기록은 최근 200개이며 기존 전체 대화 기록·기억 DB는 유지됩니다. 감시 파일 위치는 기존 DB와 동일하며 `BOT_DATA_DIR`도 지원합니다.
- **복장:** 캐릭터 편집에 기본 복장과 현재 복장이 있습니다. 현재 복장이 비어 있으면 기본 복장을 참고하고, 둘 다 비어 있으면 미지정으로 참고합니다. AI는 필요한 장면에서만 복장을 참고하며 지정되지 않은 옷·장신구를 추가하지 않도록 지시받습니다. 저장 후 재시작하면 반영됩니다.
- **본서버 사용자 관계:** 해당 캐릭터 봇의 `/관계설정 relation:고용인 description:저택에서 3년째 근무`로 자기 캐릭터와의 관계를 지정합니다. `/관계보기`, `/관계초기화`도 사용합니다. 본서버와 개인 서버 모두 서버 ID·사용자 ID·캐릭터별로 분리하며, 설정이 있으면 해당 서버 대화에 우선 반영합니다. 성격과 세계관은 유지합니다. 기존 관리자 전용 관계 명령도 유지되며 서버별 관계가 없으면 기존 관계를 참고합니다.
- **카테고리 관리:** 셋업의 카테고리 화면에서 키와 표시 이름을 추가·수정·삭제합니다. 장소 편집에서 카테고리 키를 선택하고, 재시작 후 `/서버초기화`를 실행하면 빈 카테고리도 생성합니다. 사용 중인 카테고리는 장소를 다른 그룹으로 변경한 뒤 삭제합니다. 설정 삭제·이름 변경은 기존 Discord 카테고리나 채널을 삭제·이동하지 않습니다.
- **가중치 휠 방지:** 숫자 입력칸 위에서 휠을 돌려도 값이 바뀌지 않으며 화면 스크롤에만 사용합니다. 숫자는 직접 입력하거나 화살표 버튼으로 변경합니다.

기존 사용자는 업데이트 전 봇을 정지하고 세 실행 파일을 교체하거나 셋업의 자동 업데이트를 사용하세요. 기존 `config/`, `prompts/`, `.env`, DB를 새 예제로 덮어쓰지 마세요. 새 필드는 기존 설정에 없어도 정상 동작합니다.
