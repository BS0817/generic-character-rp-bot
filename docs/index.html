Generic Character RP Bot

캐릭터, 장소, 세계관을 직접 정의할 수 있는 멀티 캐릭터 Discord RP 봇 프레임워크입니다.

Windows 다운로드초보자 설치 가이드GitHub 저장소

주요 기능

  • 여러 Discord 캐릭터 봇을 하나의 프로그램에서 동시에 실행
  • 캐릭터별 성격, 말투, 생활 습관, 목표, 소지품, 개인실 설정
  • 장소별 Discord 채널과 캐릭터별 방문 선호도 설정
  • 수면, 기상, 외출, 약속, 장소 자동 이동
  • 캐릭터의 자율 발언과 캐릭터끼리의 대화
  • 사용자 및 캐릭터 사이의 관계와 장기 기억
  • 본서버, 개인 RP 서버, DM의 상태를 서로 분리
  • 봇이 꺼져 있던 동안 받은 사용자 멘션과 답글 복구
  • 세계관 시간대와 주요 기능별 ON/OFF 설정
  • /서버초기화를 통한 장소 및 개인실 채널 자동 생성

사용자는 봇에게 무엇을 할 수 있나요?

  • 캐릭터를 @멘션해서 직접 대화하기
  • 캐릭터와 DM으로 별도의 대화 이어가기
  • 개인 RP 서버에서 본서버와 분리된 관계와 상황으로 역할극하기
  • 대화를 통해 캐릭터와 관계와 기억을 장기적으로 쌓기
  • 같은 장소에 있는 캐릭터들의 자율 대화와 생활을 지켜보기
  • /기능설정보기로 현재 활성화된 기능 확인하기
  • /서버초기화로 설정된 장소와 개인실 채널 준비하기

설치

Releases에서 Windows ZIP을 받은 뒤 RPBot_Setup.exe를 먼저 실행하고, 설정이 끝나면 RPBot.exe를 실행합니다.

초기 공개 버전이며 기능과 설치 경험을 계속 개선하고 있습니다.
