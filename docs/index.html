Generic Character RP Bot · v0.1.7

나만의 캐릭터와 세계를
Discord에서 만나보세요.

RPBot은 캐릭터의 성격과 말투, 장소, 세계관을 직접 설정하는 멀티 캐릭터 RP 봇입니다. 사용자와 대화하고 기억을 쌓으며, 선택한 기능에 따라 이동·식사·수면 같은 생활을 이어갑니다.

Windows 다운로드 초보자 설치 가이드 Railway 운영 가이드 GitHub 저장소 투네이션으로 후원하기

어떤 기능이 있나요?

캐릭터와 대화

  • 여러 캐릭터 봇을 동시에 운영
  • 캐릭터의 자율발언과 같은 장소의 봇끼리 대화
  • 성격·말투·중요 설정을 작성하는 프롬프트 가이드
  • 세계 규칙과 별도의 공통 대화 규칙, 반복 발언 억제
  • 현장 역할극·메신저 대화 방식 선택
  • 복장 취향과 기본·현재 복장 설정
  • 사용자·캐릭터 관계와 장기 기억

장소와 생활

  • 장소·개인실·카테고리, 방문 선호도와 출입 설정
  • 자동 이동·수면·기상·외출·약속
  • 좌석 정원과 동석자, 장소별 메뉴와 단계별 식사
  • 낮잠·수면 품질, 훈련 등 단계별 활동
  • 물건 대여·반환 기록과 복장 젖음·건조
  • 날씨·기온과 환경 상태 표시

달력과 일정

  • 현실 날짜 또는 지정한 가상 날짜로 세계 운영
  • 날짜·요일·계절 표시와 계절별 날씨
  • 캐릭터의 요일별 활동 일정
  • 장소의 영업 요일·시간
  • 생일·결혼기념일·커플 100일·일회성 행사
  • 기념일의 공개 여부와 아는 캐릭터 지정

PC에서 설정하고 관리

  • 한국어 셋업 창에서 캐릭터·장소·관계 편집
  • 탭을 바꿔도 입력 유지, 전체 저장과 저장 후 실행
  • 기능별 켜기·끄기와 필요한 관련 기능 안내
  • 연결·장소·활동·기분·허기·피로·좌석 모니터링
  • 최근 대화·오류·생성 결과 확인과 기억 조회·삭제
  • 설정 백업·복원과 정식 버전 업데이트

새 생활 확장 기능은 기본적으로 꺼져 있습니다. 필요한 기능을 켜고 캐릭터와 장소를 설정하세요. 개인 RP와 DM은 월드와 분리된 대화 범위를 사용할 수 있습니다.

대화하는 사용자는 무엇을 할 수 있나요?

  • 캐릭터를 @멘션하거나 메시지에 답장해 대화하기
  • 운영자가 허용한 개인 RP·공동 RP·DM에서 별도의 장면 이어가기
  • 대화 범위에 맞는 프로필과 캐릭터와의 관계 설정하기
  • 대화와 사건을 통해 기억과 관계 쌓기
  • 같은 장소의 캐릭터들이 나누는 대화와 생활 지켜보기
  • /관계설정, /관계보기, /관계초기화로 자신의 관계 관리하기
  • /기능설정보기로 활성화된 기능 확인하기

이용 가능한 대화 범위와 명령어는 운영자의 설정·허용 사용자·채널 권한에 따라 달라집니다.

운영자는 무엇을 할 수 있나요?

  • 자신의 캐릭터와 세계관을 만들고 캐릭터별 Discord 봇 연결하기
  • 장소·좌석·메뉴·개인실·초기 관계·생활 일정을 구성하기
  • 공통 규칙과 캐릭터별 프롬프트로 말투·행동의 기준 정하기
  • 세계 달력과 기념일을 설정하고 필요한 생활 기능 선택하기
  • PC 관리 창에서 봇을 실행·정지하고 현재 상태와 기록 확인하기
  • 관리 권한으로 /서버초기화를 실행해 설정된 카테고리·장소 채널 준비하기

시작하는 방법

  1. Windows ZIP을 다운로드하고 전체 압축을 풉니다.
  2. RPBot_Setup.exe에서 OpenAI API 키와 Discord 연결 정보를 설정합니다.
  3. 예시를 참고해 캐릭터 추가로 자신의 캐릭터를 만들고 장소·프롬프트·관계를 설정합니다.
  4. 전체 저장 후 봇 실행을 누르거나 RPBot.exe를 실행합니다.

Windows 배포판은 Python 설치 없이 사용할 수 있습니다. PC 운영은 실행 중인 컴퓨터가 필요하며, 클라우드 운영은 Railway 가이드를 참고하세요. OpenAI API 사용료와 클라우드 요금은 별도로 발생할 수 있습니다.

기존 사용자는 봇을 종료한 뒤 셋업의 업데이트 메뉴를 이용하세요. 수동 업데이트는 실행 파일 세 개만 교체하고 기존 설정·프롬프트·키·대화 데이터를 유지하세요.
