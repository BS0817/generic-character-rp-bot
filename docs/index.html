캐릭터별 프롬프트, 자동 이동, 수면과 외출, 자율발언, 캐릭터끼리의 대화, 장기 기억, 개인 RP 서버, DM 등을 설정 파일로 조절할 수 있습니다.

설치

Releases에서 Windows ZIP을 받은 뒤 RPBot_Setup.exe를 먼저 실행하고, 설정이 끝나면 RPBot.exe를 실행합니다.

초기 공개 버전이며 기능과 설치 경험을 계속 개선하고 있습니다.
