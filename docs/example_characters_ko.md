# 기본 예시 캐릭터

엘리스·사야·유리는 설정 작성 방법을 보여 주는 참고용 캐릭터입니다. 셋업의 **캐릭터 추가**로 자신의 캐릭터를 만들고, 사용하지 않는 예시는 삭제하세요. 예시에는 봇 토큰이나 API 키가 없습니다.

| 캐릭터 | 성격과 목표 | 장소 취향 |
|---|---|---|
| 엘리스 | 밝고 다정함. 작은 소품가게를 꿈꿈 | 개인실·거실·도서관 |
| 사야 | 과묵하고 자기 시간을 존중함. 작곡한 곡 조회수 100만이 목표 | 개인실·조용한 도서관 |
| 유리 | 차분하고 따뜻함. 부모님의 옛 서점을 되찾고 싶어 함 | 도서관·개인실·거실 |

엘리스와 사야는 음악을 통해 가까워진 친구, 엘리스와 유리는 가게의 꿈을 응원하는 친구, 사야와 유리는 침묵도 편안한 친구입니다. 서로 반말을 쓰며 작은 의견 차이도 있습니다. 상세 설정은 캐릭터 프롬프트와 관계 파일을 참고하세요.

공용 장소 5곳과 개인실 3곳에 가중치·시간대 배율·활동을 설정했습니다. 카페에는 시간대별 메뉴가 있고, 좌석이 있는 공용 장소에는 정원이 있습니다. 모든 곳에 메뉴와 좌석이 필요한 것은 아닙니다. 다른 캐릭터의 개인실 가중치는 0이며 개인실은 주인만 출입하도록 설정했습니다.

선택 기능은 세계관의 기능 설정에서 켜세요. 복장 취향은 세계관 설정과 캐릭터별 설정을 모두 켜야 적용됩니다. 유리는 개인별 복장 취향을 꺼 둔 예시입니다. 예시를 넣는 업데이트가 사용자의 기존 설정·프롬프트를 덮어쓰지는 않습니다.

요일별 일정도 참고용으로 들어 있습니다. 엘리스는 화·목 오후에 카페에서 가게 아이디어를 메모하고, 사야는 월·수·금 오후에 도서관에서 작곡 아이디어를 정리하며, 유리는 평일 오전에 도서관에서 책과 서점 운영을 공부합니다. 일정 기능은 기본적으로 꺼져 있습니다. 장소의 영업시간도 입력 예시이며 각 장소의 적용 스위치는 꺼져 있습니다. 기능과 장소별 적용을 켠 뒤 원하는 시간으로 조정하세요.
